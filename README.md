# ClipFormatter (クリップボード自動整形ツール)

クリップボードの変更を検知し、指定されたルール（数値丸め・列抽出・変数テンプレート）に従って自動でテキストを変形・上書きするデスクトップユーティリティです。
論文執筆（TeX）、実験データ整理、ログ解析、Excel連携などのコピペ作業を効率化します。

---

## 主な機能

1. **定型ルールモード (Preset Mode)**
   - **数値 / パーセント丸め**: 正規表現により小数やパーセント表記（例: `95.2251%` -> `95.23%`）を指定桁数に自動丸め。
   - **特定列の抽出**: カンマ・タブ・スペース等の区切り文字を指定し、指定した列（1-based、負数による末尾指定対応）のみを抽出（複数行対応）。

2. **プログラマブルモード (Variable/Template Mode)**
   - **パターンマッチ形式（文脈抽出・推奨）**:
     - 文章中に `{変数名}` を埋め込んだパターンを指定し、マッチした箇所を出力テンプレートへ自在に並び替え・置換。
     - 長い文章中の一部置換や、複数行データの一括置換に対応。
     - `{` や `}` をリテラルとして扱うためのエスケープ（`\{`, `\}` または `{{`, `}}`）をサポート。
   - **区切り文字形式（CSV/TSV）**:
     - カンマやタブ等で区切られたデータを変数にマッピングして展開。
   - **自動バリデーション & スキップ**: パターンに一致しない場合や要素数不一致、未定義変数が含まれる場合は変換を実行せず安全にスキップ。

3. **グローバルホットキー & バックグラウンドトグル**
   - いつでも `Ctrl + Alt + X` で自動変換の有効/無効を即時切り替え可能。

4. **安全設計 (無限ループ防止 & 排他制御)**
   - アプリ自身が書き込んだテキストを再検知して無限ループに陥ることをハッシュ比較により完全防止。
   - クリップボードのOSロック競合時もエラーを握りつぶして安全に再試行。

5. **設定の自動永続化**
   - 設定した値（桁数、抽出列、区切り文字、変数定義、テンプレート等）はアプリ終了時に `config.json` に保存され、次回起動時に自動復元。

6. **トースト通知**
   - 変換完了時や要素数不一致によるスキップ時に、画面上に軽量なミニ通知を表示。

## 動作要件 & セットアップ

- **Python**: 3.10 以上
- **対応OS**: Windows 11 / 10 / macOS / Linux

### 仮想環境の準備とパッケージインストール

本リポジトリ内の仮想環境を使用する場合:

```powershell
# 仮想環境のアクティベート (Windows PowerShell)
.\clip-formatter\Scripts\Activate.ps1

# 依存パッケージのインストール
pip install -r requirements.txt
```

---

## 起動方法

```powershell
# メインアプリケーションの起動
python main.py
```

起動後、画面上部の「自動変換を有効化」スイッチをONにするか、ホットキー `Ctrl + Alt + X` を押すことで監視がスタートします。

## 具体的な使用例

### 例1: 数値の小数丸め
- **設定**: 小数点以下桁数 `2`
- **コピー内容**:
  ```text
  Accuracy: 92.3456%, Loss: 0.08129
  ```
- **貼り付け結果**:
  ```text
  Accuracy: 92.35%, Loss: 0.08
  ```

### 例2: 複数行データからの特定列抽出
- **設定**: 区切り文字 `,`、抽出列番号 `1, -1` (先頭列と末尾列)
- **コピー内容**:
  ```text
  ID, Name, Age, Department
  101, Alice, 28, Research
  102, Bob, 34, Development
  ```
- **貼り付け結果**:
  ```text
  ID, Department
  101, Research
  102, Development
  ```

### 例3: 文章内の一部の並び替え・置換（パターンマッチ形式）
- **設定**:
  - モード: `パターンマッチ形式`
  - 入力パターン: `私は{a}時間で{b}つのりんごを食べました`
  - 出力テンプレート: `私は{b}時間で{a}つのりんごを食べました`
- **コピー内容**:
  ```text
  日記：私は1時間で2つのりんごを食べました。
  ```
- **貼り付け結果**:
  ```text
  日記：私は2時間で1つのりんごを食べました。
  ```

### 例4: 一部文字列の固定置換（パターンマッチ形式）
- **設定**:
  - モード: `パターンマッチ形式`
  - 入力パターン: `高橋くんと{a}くんと遊びました`
  - 出力テンプレート: `高橋くんと伊藤くんと遊びました`
- **コピー内容**:
  ```text
  高橋くんと佐藤くんと遊びました
  ```
- **貼り付け結果**:
  ```text
  高橋くんと伊藤くんと遊びました
  ```

### 例5: 波括弧を含むテキストのエスケープ
- **設定**:
  - 入力パターン: `fn(\{{x}\}) = \{{val}\}` (または `fn({{{x}}}) = {{{val}}}`)
  - 出力テンプレート: `result[\{{x}\}] = \{{val}\}`
- **コピー内容**:
  ```text
  fn({id}) = {100}
  ```
- **貼り付け結果**:
  ```text
  result[{id}] = {100}
  ```

### 例6: 変数テンプレートによるCSVの順序入れ替え（区切り文字形式）
- **設定**:
  - モード: `区切り文字形式`
  - 区切り文字: `,`
  - 入力フォーマット: `id, name, score`
  - 出力テンプレート: `[ID:{id}] {name} => {score}点`
- **コピー内容**:
  ```text
  1, 田中, 85
  2, 佐藤, 92
  ```
- **貼り付け結果**:
  ```text
  [ID:1] 田中 => 85点
  [ID:2] 佐藤 => 92点
  ```
