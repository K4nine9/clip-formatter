# ClipFormatter (クリップボード自動整形ツール)

クリップボードの変更を検知し、指定されたルール（数値丸め・列抽出・変数テンプレート）に従って自動でテキストを変形・上書きするデスクトップユーティリティです。
論文執筆（TeX）、実験データ整理、ログ解析、Excel連携などのコピペ作業を効率化します。

---

## 主な機能

1. **定型ルールモード (Preset Mode)**
   - **整数部フォーマット (小数点以上)**: 「変更しない」「ゼロ埋め (パディング)」から選択。
   - **小数部フォーマット (小数点以下)**:
     - モード: 「変更しない」「小数丸めモード (可変長)」「ゼロ埋めモード (固定長)」から選択。
     - 超過時処理: 「四捨五入」「切り捨て」から選択（小数丸め・ゼロ埋め時に連動）。
   - **特定列の抽出**: タブ・カンマ・スペース等の区切り文字を指定し、指定した列のみを抽出（複数行対応）。
   - **改行・ハイフン除去 (Unwrap)**: PDFからコピーした際の不要な改行や行末ハイフネーション（`differ-\n ent` → `different`）を自然に結合（段落区切り保持、和文スマート結合対応）。

2. **LaTeXモード (LaTeX Mode)**
   - **表組み (Table) 変換**: Excel/TSV/CSVをコピーするだけで、`\begin{tabular}` や `booktabs` (`\toprule`, `\midrule`, `\bottomrule`)、または本体のみの LaTeX 構文、さらには **Markdown 表 (`| Col1 | Col2 |`)** へ即座に変換。
   - **最良値の自動太字化 (Highlight Best)**: 各列の最大値（または最小値）を自動判定し、LaTeXなら `\textbf{...}`、Markdownなら `**...**` で太字強調。
   - **数式 (Formula) 双方向変換**:
     - 手打ち数式 → LaTeX: `1 / (2x)` → `\frac{1}{2x}`, `sqrt(x)` → `\sqrt{x}`, `alpha^2` → `\alpha^{2}`, `*` → `\cdot`, `+-` → `\pm`（`$ ... $` 自動囲み対応）。
     - LaTeX → 手打ち数式（逆変換）: `\frac{1}{2x}` → `(1) / (2x)`。

3. **プログラマブルモード (Variable/Template Mode)**
   - **パターンマッチ形式（文脈抽出・推奨）**: 文章中に `{変数名}` を埋め込んだパターンからマッチした部分をテンプレートへ展開。波括弧エスケープ対応。
   - **区切り文字形式（CSV/TSV）**: 区切りデータから変数にバインドして出力テンプレートへ展開。

4. **クリップボードの Undo（元に戻す）機能**
   - ショートカット `Ctrl + Alt + Z` または画面上の「元に戻す」ボタンで、自動変換直前のオリジナルテキストをワンタッチで完全復元。

5. **リアルタイム変換テスト・プレビュー枠**
   - ウィンドウ下部の開閉アコーディオンから、クリップボードを上書きすることなく手動で設定の挙動を即座にシミュレーション・結果コピー可能。

6. **システムトレイ（タスクトレイ）常駐化**
   - 「×」ボタンで閉じてもタスクバーを占有せず、画面右下のトレイアイコンへ格納。トレイメニューから再表示・トグル・終了を操作可能。

7. **プリセット（プロファイル保存・切り替え）機能**
   - 「LaTeX 表組み」「LaTeX 数式変換」「PDF 改行結合」「通常数値丸め」など、用途に応じた設定を名前をつけて複数保存し、ドロップダウンからワンクリックで瞬時に切り替え可能。

8. **柔軟な区切り文字セレクタ**
   - カンマ `,`、タブ `\t`、半角スペース、全角スペース、コロン `:`、セミコロン `;`、ピリオド `.`、および任意のカスタム文字をドロップダウンから安全・簡単に指定可能。

9. **グローバルホットキー & バックグラウンドトグル**
   - いつでも `Ctrl + Alt + X` で自動変換の有効/無効を即時切り替え可能。

10. **安全設計 (無限ループ防止 & 排他制御)**
    - アプリ自身が書き込んだテキストを再検知して無限ループに陥ることをハッシュ比較により完全防止。

## 動作要件 & セットアップ

- **Python**: 3.10 以上
- **対応OS**: Windows 11 / 10 / macOS / Linux

### 仮想環境の準備とパッケージインストール

本リポジトリ内の仮想環境を使用する場合:

```powershell
# 仮想環境のアクティベート (Windows PowerShell)
.\clip-formatter\Scripts\Activate.ps1

# 依存パッケージのインストール
pip install -r requirements.txt
```

---

## 起動方法

```powershell
# メインアプリケーションの起動
python main.py
```

起動後、画面上部の「自動変換を有効化」スイッチをONにするか、ホットキー `Ctrl + Alt + X` を押すことで監視がスタートします。

---

## ホットキー一覧

| ホットキー | 機能 |
| :--- | :--- |
| `Ctrl + Alt + X` | 自動変換機能の ON / OFF をトグル切り替え |
| `Ctrl + Alt + Z` | 直前の変換をキャンセルし、元のクリップボード内容に復元 (Undo) |

## 具体的な使用例

### 例1: 数値の小数丸め
- **設定**: 小数点以下桁数 `2`
- **コピー内容**:
  ```text
  Accuracy: 92.3456%, Loss: 0.08129
  ```
- **貼り付け結果**:
  ```text
  Accuracy: 92.35%, Loss: 0.08
  ```

### 例2: 数字のゼロ埋め ＋ 切り捨て（整数・小数独立フォーマット）
- **設定**:
  - 整数部: `ゼロ埋め`、桁数 `3`
  - 小数部: `ゼロ埋めモード (固定長)`、桁数 `2`、超過時処理 `切り捨て`
- **コピー内容**:
  ```text
  Scores: 5, 42.1, 3.149, -7.5, 98.2%
  ```
- **貼り付け結果**:
  ```text
  Scores: 005.00, 042.10, 003.14, -007.50, 098.20%
  ```
  ※不足桁は `0` で埋められつつ、`3.149` は四捨五入（`3.15`）ではなく切り捨て（`3.14`）されます。

### 例3: 複数行データからの特定列抽出
- **設定**: 区切り文字 `,`、抽出列番号 `1, -1` (先頭列と末尾列)
- **コピー内容**:
  ```text
  ID, Name, Age, Department
  101, Alice, 28, Research
  102, Bob, 34, Development
  ```
- **貼り付け結果**:
  ```text
  ID, Department
  101, Research
  102, Development
  ```

### 例4: 文章内の一部の並び替え・置換（パターンマッチ形式）
- **設定**:
  - モード: `パターンマッチ形式`
  - 入力パターン: `私は{a}時間で{b}つのりんごを食べました`
  - 出力テンプレート: `私は{b}時間で{a}つのりんごを食べました`
- **コピー内容**:
  ```text
  日記：私は1時間で2つのりんごを食べました。
  ```
- **貼り付け結果**:
  ```text
  日記：私は2時間で1つのりんごを食べました。
  ```

### 例5: 一部文字列の固定置換（パターンマッチ形式）
- **設定**:
  - モード: `パターンマッチ形式`
  - 入力パターン: `高橋くんと{a}くんと遊びました`
  - 出力テンプレート: `高橋くんと伊藤くんと遊びました`
- **コピー内容**:
  ```text
  高橋くんと佐藤くんと遊びました
  ```
- **貼り付け結果**:
  ```text
  高橋くんと伊藤くんと遊びました
  ```

### 例6: 波括弧を含むテキストのエスケープ
- **設定**:
  - 入力パターン: `fn(\{{x}\}) = \{{val}\}` (または `fn({{{x}}}) = {{{val}}}`)
  - 出力テンプレート: `result[\{{x}\}] = \{{val}\}`
- **コピー内容**:
  ```text
  fn({id}) = {100}
  ```
- **貼り付け結果**:
  ```text
  result[{id}] = {100}
  ```

### 例7: 変数テンプレートによるCSVの順序入れ替え（区切り文字形式）
- **設定**:
  - モード: `区切り文字形式`
  - 区切り文字: `,`
  - 入力フォーマット: `id, name, score`
  - 出力テンプレート: `[ID:{id}] {name} => {score}点`
- **コピー内容**:
  ```text
  1, 田中, 85
  2, 佐藤, 92
  ```
- **貼り付け結果**:
  ```text
  [ID:1] 田中 => 85点
  [ID:2] 佐藤 => 92点
  ```

### 例8: Excel/TSVからLaTeX表組み（booktabs）への一発変換
- **設定**: モード `LaTeXモード (表組み)`、区切り文字 `タブ (\t)`、スタイル `booktabs`
- **コピー内容 (Excelからコピー)**:
  ```text
  Model	Accuracy	Loss
  Baseline	0.852	0.128
  Ours	0.941	0.034
  ```
- **貼り付け結果**:
  ```latex
  \begin{tabular}{lrr}
  \toprule
  Model & Accuracy & Loss \\
  \midrule
  Baseline & 0.852 & 0.128 \\
  Ours & 0.941 & 0.034 \\
  \bottomrule
  \end{tabular}
  ```

### 例9: 手打ち数式からLaTeX数式への変換
- **設定**: モード `LaTeXモード (数式)`、変換方向 `手打ち → LaTeX`、環境 `インライン ($ ... $)`
- **コピー内容**:
  ```text
  1 / (2x) + alpha^2 +- sqrt(y)
  ```
- **貼り付け結果**:
  ```latex
  $\frac{1}{2x} + \alpha^{2} \pm \sqrt{y}$
  ```

### 例10: 論文PDFコピペの改行・ハイフネーション除去
- **設定**: モード `定型ルールモード`、`不要な行末改行・ハイフンを結合する` をON
- **コピー内容 (PDFからコピー)**:
  ```text
  Recent advances in deep learn-
  ing have enabled significant
  improvements in NLP.
  ```
- **貼り付け結果**:
  ```text
  Recent advances in deep learning have enabled significant improvements in NLP.
  ```
